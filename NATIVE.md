# MailDesk 2 — Rust + GPUI

Нативное настольное приложение: запускается своим окном. Браузер и локальный сервер не нужны. Rust, Go, Node.js и Python пользователю устанавливать не требуется. Интернет нужен для SMTP и DeepSeek.

## Запуск

Нативные архивы называются **MailDesk-Native-…zip**. Сборки Windows и macOS создаёт [GitHub Actions](https://github.com/kegazani/smtp-send-script/actions/workflows/native.yml) на соответствующих системах. После успешной сборки всех пяти вариантов workflow сохраняет общие архивы в `dist/`. До появления этих архивов используйте рабочую веб-версию 1.1.1 из `dist/MailDesk-…zip`: это отдельные сборки.

- Windows: распакуйте весь архив и откройте `MailDesk.exe`. Внутри EXE есть иконка.
- macOS: распакуйте и откройте `MailDesk.app`. Иконка входит в пакет. Сборка не подписана сертификатом Apple; первый запуск разрешается в настройках конфиденциальности macOS.
- Linux x64: распакуйте и запустите `./maildesk`. Нужны обычные библиотеки рабочего стола: Fontconfig, FreeType, XKB Common/X11, Vulkan с драйвером GPU и X11 либо Wayland. Для диалогов файлов используется системный XDG Desktop Portal. Архив Linux собран для современной glibc; переносимость на старые дистрибутивы не заявляется.

Перед открытием того же проекта закройте веб-версию. Новая версия использует ту же пользовательскую папку `MailDesk` и читает `project.json` версии 1/2 и `credentials.json`. Для проекта v1 сохраняется резервная копия. Если приложение закрылось во время отправки, статус становится «Проверьте доставку»; перед повтором проверьте отправленные письма у провайдера.

## Подключения и проекты

Откройте **Подключения**, задайте SMTP Mail.ru (`smtp.mail.ru`, `465`, `ssl`), логин, пароль приложения, адрес и имя отправителя, ключ DeepSeek. **Проверить SMTP** проверяет TLS и вход без отправки письма.

Личный `maildesk.env` рядом с EXE/бинарником или рядом с `MailDesk.app` может содержать `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL`, `LLM_API_KEY`. Уже сохранённые настройки имеют приоритет. `companies.csv` рядом с приложением импортируется только в пустой профиль. Общие архивы не содержат ни учётных данных, ни реальных компаний.

**Загрузить CSV / JSON** принимает прежний формат CSV (`Company`, `Email`, `Overview`, UTF-8; запятая или точка с запятой). JSON переносит компании, черновики, историю, шаблон и вложения между людьми; подключения в него не входят. **Отчёт CSV** сохраняет таблицу без содержимого файлов.

В **Наша компания** укажите факты о себе и предложение. DeepSeek использует эти сведения и описание конкретного получателя. Письмо по умолчанию используется только для компаний без описания. Ошибка DeepSeek сохраняет прежний черновик и отображается в редакторе.

Выберите компании галочками, создайте письма, прочитайте и отредактируйте их. **Выделить все в фильтре** выделяет доступные письма текущего фильтра. **Написать** создаёт обычное письмо с несколькими адресатами; они видят общий список «Кому».

Вложения можно добавить в редакторе или сразу выбранным письмам. Максимум: 10 МБ на файл, 15 МБ и 20 вложений на письмо, 100 МБ уникальных файлов на проект. В JSON файлы сохраняются вместе с проектом.

**Отправить выбранные → Подтвердить → Да, точно подтверждаю** отправляет выбранные письма. Подтверждение истекает через пять минут, привязано к содержимому писем и подключениям и используется один раз. **Остановить очередь** останавливает отправку после текущего письма. Ошибки отмечены красным, отправленные строки — серым и недоступны для повторного выбора. Есть фильтры статусов.

## Разработка

Код движка: `crates/maildesk-core`. Нативный интерфейс: `crates/maildesk-gpui`, настоящий GPUI через GPUI Kit 0.7.3. `Cargo.lock` фиксирует зависимости. Требуется актуальный Rust stable; проверено на Rust 1.99.1.

```sh
cargo test --locked -p maildesk-core
cargo build --locked -p maildesk-gpui
cargo run --locked -p maildesk-gpui -- --data-dir /tmp/maildesk-dev --test-recipient ddkritsin@gmail.com
cargo build --locked --release -p maildesk-gpui
python3 scripts/package_native.py --binary target/release/maildesk --label Linux-x64
```

На Linux установите пакеты разработки Fontconfig, FreeType, libxkbcommon, libxkbcommon-x11, Wayland и Vulkan. На macOS нужны Xcode Command Line Tools и Metal SDK, на Windows — Visual Studio Build Tools с C++ и Windows SDK. Нативную сборку под macOS выполняйте на macOS, под Windows — на Windows.

Во время разработки реальные тестовые письма разрешены только на **ddkritsin@gmail.com**; всегда запускайте с `--test-recipient`. Автотесты SMTP используют только локальный TCP-имитатор без внешних получателей. Облачная проверка Linux использует Xvfb и программный Vulkan; она не заменяет проверку интерфейса на реальных Windows/macOS.

Веб-версия продолжает собираться независимо командой `go build .`. Её описание и архивы находятся в README.
